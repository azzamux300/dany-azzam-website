# Dany Azzam Cars – website

Black, Arabic-first (with English switch) website for Dany Azzam Cars for All.

- `index.html` – the whole site (home with 3D intro, why choose us, collection page with search, car detail gallery, footer).
- `cars/<slug>/01.jpg …` – photos for each car. `01.jpg` is the cover.
- `bg/porsche.jpg` – background of the collection page.

Hosted on Netlify from this repository: every push to `main` updates the live site.
